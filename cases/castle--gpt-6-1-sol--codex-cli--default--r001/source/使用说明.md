# 丰穗领地

直接用 Chrome 或 Edge 打开 `index.html`。Three.js 和场景均已内嵌，不需要联网或启动服务。

- 拖拽：环绕旋转；滚轮或双指：缩放。
- 下方控制：晴朗、细雨、晨雾、飘雪；时辰和风力。
- 右上角圆箭头：恢复初始视角。
- 眼睛按钮或 H：隐藏 / 显示界面；Escape 也可恢复界面。
- 关闭“动效”可保持静态模型；遵循系统“减少动态效果”设置。

所有模型为程序生成几何体，角色为受光的二维像素立牌。角色以 2–6 帧每秒切换动作，每 22 秒循环包含 16 秒驻留劳作和 6 秒近距离移动。雪天表现为飘雪，不模拟积雪。

## 编辑与重新构建

`src/` 中分别保存城堡、地形、村庄、角色、天气及主场景。界面样式在 `src/shell.html`。

在此目录执行 `npm install`，然后 `npm run build`，会更新可独立打开的 `index.html`。Three.js 的 MIT 许可见 `THREE-LICENSE.txt`。
