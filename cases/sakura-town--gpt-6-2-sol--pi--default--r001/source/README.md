# 樱花小镇 · Sakura Town

一个使用 Three.js 和 Vite 制作的日式动画风格 3D 生活小品。沿站前小路穿过铁路，在茶屋、车站和河岸之间散步。整座镇子都在普通的平面坐标中；山脊、树林与河流围出可步行的盆地。

## 开始散步

需要 Node.js 20.19+ 或 22.12+ 和支持 WebGL 2 的浏览器。

```sh
npm ci
npm run dev
```

打开 Vite 打印的地址。从左侧的散步手记出发。

- **WASD / 方向键**移动，也可以点击或轻触路面步行。
- **E** 或屏幕上的互动提示：交谈、进出建筑、拾起物品。
- **M** 打开地图；点击手记里的地点，可步行到当前目的地。
- 启用右上角的环境音后，可以听见风、鸟鸣和近处的道口警铃。

便当委托串起春风茶屋、铁路道口和樱丘车站。完成后，沿河走走，还有一段小插曲。列车会鸣铃封闭道口、停靠站台，再继续驶离；请在线外等警铃停止、栏杆抬起。三位居民会按钟点改变站位或沿街散步。打开指南、地图或对话时，镇上的时钟会暂停。进度和位置自动存于当前浏览器。

## 构建与测试

```sh
npm test
npm run build
npm run preview
```

部署时将 `dist/` 交给静态服务器。场景模型、招牌、花瓣与音效在本地生成，无需下载外部资源。
