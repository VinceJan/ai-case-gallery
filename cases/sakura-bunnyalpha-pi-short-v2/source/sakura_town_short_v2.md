# 《樱花小镇》Sakura Town —— 简洁版提示词

使用 **Three.js + Vite** 从零完成一个可运行、可游玩的 3D 日式乡镇生活模拟游戏《樱花小镇》。世界采用普通平面坐标，小镇位于群山、树林与河谷环绕的盆地中，以自然地貌形成边界，不使用球面或曲面世界。整体保持统一的日式动画背景 / cel-shading 风格，规模克制、密度优先。重点做好少量核心街区、少量可进入建筑、少量有作息的居民、真实运行的铁路与道口，以及若干高质量交互和自然发生的小任务。不要追求大地图和功能堆砌；宁可减少内容，也要保证完整、稳定、有生活感并真正可玩。
