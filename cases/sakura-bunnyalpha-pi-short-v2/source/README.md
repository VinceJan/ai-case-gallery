# 《樱花小镇》Sakura Town

一个用 **Three.js + Vite** 从零做出来的 3D 日式乡镇生活模拟游戏。

群山与河谷围出一个盆地，盆地中央是樱花町：主街、商店街、车站与穿过镇子的铁路、
河上的桥、坡地上的稻荷神社、河岸公园、樱花学园、南边的一片水田。
八位居民各自按作息生活，列车真的会进站，平交道口真的会警铃大作然后落下栏杆。

<p align="center"><em>「群山与河谷之间的小镇 —— 铁路会来，人也会来」</em></p>

---

## 运行

```bash
npm install     # 只需要 three + vite
npm run dev     # http://127.0.0.1:5373
```

开发服务器固定使用端口 **5373**（`strictPort`），不会占用其他实例的端口。
生产构建：`npm run build`，预览同样跑在 5373（`npm run preview`）。

需要 Node 18+ 与支持 WebGL2 的浏览器。

## 镇子是什么样的

* **地形**：196×196 的高度场，四周是抬升的群山与针叶林带，中间是盆地。
  河谷从地形里真实地切下去，桥跨在河上，铁道路基沿线把地面压平。
* **街区**：一条主街串起全部生活；北横街、中横街、南横街与站前路组成路网；
  神社参道、公园小径、田埂小路是次级道路。中央广场有纪念碑、喷泉、钟塔。
* **建筑**：20 栋程序化生成的日式建筑 —— 木造民宅、切妻屋顶、瓦屋顶、
  女儿墙的便利店、带钟塔的学校、带雨棚的站房、带千木的拜殿。
  招牌文字是 Canvas 现场画的。
* **室内**：9 个可进入的房间（家、山田商店、便利店、拉面店、咖啡馆、小酒馆、
  车站、邮局、神社拜殿），各有自己的灯光、家具和柜台交互点。
* **植被**：樱花林、松林、阔叶林、灌木、草丛，全部用 InstancedMesh 散播，
  顶点着色器带风摆。飘落的花瓣是实时粒子。
* **铁路**：道砟 + 轨枕 + 双股钢轨沿真实样条铺设，两端钻进山里的隧道。
  机车带两节车厢，按弧长运行、提前减速、在站台停 9 秒。
* **道口**：列车接近 125m 开始闪灯鸣铃，78m 落杆，杆落下后玩家会被拦住，
  列车通过后杆再抬起。
* **居民**：山田三郎、花子、小林茂、美咲、健一、小夜、结衣、空 ——
  各自有按小时切换的作息表，靠路网 A* 走到下一个点，然后站桩 / 干活 / 小酌 / 参拜 / 钓鱼。
  周末美咲的作息表会换成在公园疯跑。

## 玩法

### 六个自然发生的小任务

| 任务 | 内容 |
|---|---|
| 第一件差事 | 和山田老板接活，把 📦 包裹送到田中家 |
| 三花不见了 | 在河边公园找到走丢的猫，它会一路跟着你回来 |
| 河岸的清晨 | 在小亭钓点钓上一条鱼，再送去拉面 一龙 |
| 樱花季的小-request | 在公园的樱树下收集 5 片完整的 🌸 樱花瓣 |
| 花子家的菜园 | 帮忙浇菜园，收 3 根 🥕 萝卜 |
| 去看列车吧 | 在站台上等一班列车进站，再和健一聊聊 |

任务不是从菜单里接的 —— 跟对应的人聊上几句就自然开始了。
`J` 可以随时查看进度、当前目标和背包。

### 背包与持物

买到的和捡到的东西不再只是数字：
- 在 `J` 背包里点物品即可**使用**——食物回体力，御守收进随身，车票/明信片入收藏，任务道具可拿在手上
- 拿着东西走到镇民面前按 `F` 递给他/她，会有回应（喂猫、给花子送萝卜、特殊交付自动推进任务）
- 拿在手上的物品会真的出现在角色手里；钓鱼时手上是鱼竿

### 存档

进度自动保存，无需手动操作：
- 存 localStorage，只序列化纯数据（会剥掉 `inv`/`toast` 这类运行时绑定，读档后重新绑定）
- 触发点：每 30 秒、跨天、切后台、关页
- 标题页出现「继续上次」并显示存档摘要
- 读档后背包/任务/flag 全部还原，且与存档深拷贝隔离（改动不污染存档）
- 浏览器禁用存储（隐私模式）时静默降级并提示一次，不会崩

### 设置

按 `K` 或标题页「设置」打开（自包含模块 `src/ui/settings.js`）：
- 鼠标灵敏度 0.4~2.5、Y 轴反转
- 主音量、静音
- 画质：低（关阴影）/ 均衡 / 高清（即时生效）
- 显示操作提示开关
- 设置本身也持久化

### 其它交互

* 床上睡觉推进到第二天早上（06:30，花瓣重置，体力回满）
* 长椅上坐下休息回体力
* 自动贩卖机、樱饼摊买零食
* 神社参拜，一天一次，会给一句御神的话
* 撸猫（走丢任务里那只猫会记住你）
* 7 家店可以买东西：蔬果、饭团、咖啡、拉面、清酒、车票、明信片
* 钓鱼小游戏：抛竿 → 等咬钩（咬钩瞬间按 E）→ 按住 E 把指针稳在绿区里

### 昼夜

一天约 12.5 分钟。太阳沿真实轨迹升落，天空渐变色在黎明 / 正午 / 黄昏 /
夜晚之间插值；入夜后窗户亮起暖光，街灯点亮，星星出来，猫和野鸟飞过。
周五、周末居民的作息表会切换。

## 技术

```
src/
├── main.js                 入口：引擎 / 输入 / 音频 / UI 装配
├── core/
│   ├── engine.js           渲染器、相机、主循环
│   ├── toon.js             Cel-shading 材质工厂 + 反向外壳描边
│   ├── geobuilder.js       按材质合并几何体（压 draw call）
│   ├── collide.js          OBB 碰撞 + 相机射线
│   ├── input.js            键鼠 / 指针锁定 / 触摸
│   ├── audio.js            全部音效由 WebAudio 现场合成
│   └── utils.js            噪声、缓动、折线查询
├── world/
│   ├── layout.js           唯一的世界蓝图（河/铁轨/路/建筑/路网/地标）
│   ├── terrain.js          盆地高度场、河道下切、水面、地表类型
│   ├── sky.js              渐变天穹、太阳月亮、星星、云
│   ├── materials.js        材质库 + 昼夜驱动的自发光
│   ├── buildings.js        各类日式建筑生成器
│   ├── kit.js              屋顶 / 障子 / 拉门 / 招牌 / 暖帘等构件
│   ├── props.js            鸟居、喷泉、钟塔、贩卖机、长椅…
│   ├── vegetation.js       树与草的实例化散布 + 风摆
│   ├── roads.js            路面、人行道、斑马线、桥、站台、隧道
│   ├── interiors.js        9 个可进入房间
│   └── world.js            装配 + 地面高度查询 + 室内外切换
├── entities/
│   ├── character.js        人形模型 + 程序化动画 + 表情
│   ├── player.js           第三人称控制器 + 自由轨道相机
│   ├── npc.js              居民与作息表
│   ├── nav.js              路网 A*
│   ├── train.js            轨道、道口、列车运行
│   └── animals.js          猫、鸽子、飞鸟
├── game/
│   ├── game.js             主循环、时间、交互派发、商店、任务推进、存档接线
│   ├── quests.js           任务数据与步骤机
│   ├── items.js            物品与背包
│   ├── save.js             存档序列化 + 独立自测
│   ├── dialogue.js         按时间/任务分支的台词
│   └── fishing.js          钓鱼小游戏
└── ui/
    ├── ui.js               HUD / 对话 / 日志 / 商店 / 小地图 / 转场
    ├── settings.js         设置面板（自包含，带自己的样式）
    └── style.css           日式纸感 UI
```

要点：

* **Cel-shading**：`MeshToonMaterial` + 手写色阶贴图，最暗阶刻意抬到 0.55，
  阴影通透不脏；描边用视图空间外推的反向外壳，屏幕空间等宽。
* **不依赖任何外部资源**：所有贴图（招牌、铺装、报纸、表情、花瓣）都是
  Canvas 现场画的，所有音效都是 WebAudio 现场合成的。
* **几何合并**：`GeoBuilder` 按材质合并，一栋楼通常只有 4~8 个 draw call。
* **确定性世界**：噪声全部走可播种 RNG，世界每次生成完全一致。

参考规模：约 200 个 draw call、29 万三角面、770 个几何体。

## 开发工具

`tools/` 下是自动化检查脚本（需要本机装有 Python 版 Playwright）：

```bash
node tools/selftest-save.mjs   # 存档模块自测（19 项，纯 Node，不开浏览器）
python tools/playtest.py       # 跑遍全镇各场景并截图到 shots/
python tools/gameplay.py       # 道口 / 进站 / 任务 / 采集 / 钓鱼 / 睡觉 / 商店 / 进出房屋
python tools/smoke.py          # 只用键盘/鼠标的真实操作流 + 24 小时作息巡检
python tools/camera.py         # 鼠标自由转视角 + 移动速度
python tools/systems.py        # 存档 / 背包 / 持物 / 睡姿 / 坐长椅 / 设置面板
```

所有脚本都会在结束时汇总失败项与运行时错误（全部应为 0）。
*注意：并行跑多个脚本会互相抢 dev server（5373 固定端口），请串行执行。*
