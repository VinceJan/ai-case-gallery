# 樱花小镇 Sakura Town

一个用 **Three.js + Vite** 从零构建的 3D 日式乡镇生活模拟游戏。晚春樱花季，一列慢车穿过小镇，玩家在春假期间来到镇上探望奶奶，认识居民、完成委托、体验小镇的昼夜与天气。

## 运行

```bash
npm install     # 安装 three 与 vite
npm run dev     # 开发模式（默认 http://localhost:5173）
npm run build   # 生产构建（输出 dist/）
npm run preview # 预览生产构建
```

## 玩法

- **核心循环**：在公民馆/车站的公告板接受小镇委托（送包裹、找帽子、买咖啡豆、寄信、找猫、通知列车延误、挂庙会灯笼、赏樱三景、夜樱），获得零钱与居民信任；信任度会解锁新的委托与对话。
- **铁路**：列车按时刻表从西山隧道进站、减速、停靠、开门、等待、关门、离站；道口警报与栏杆完全联动，NPC 会在道口前等待；玩家可以在停站时乘车，坐完整整一圈后再下车。
- **居民**：6 位核心居民（奶奶、站长、便利店店员、咖啡店老板、小学生、零工）各有住所、作息路线与对话，受时间/天气/事件影响；另有 4 位背景居民和一只会在镇上漫游的猫。
- **时间与天气**：24 小时昼夜循环影响光照、商店营业、窗灯、路灯、车站人流；雨天可切换，地面变潮、NPC 撑伞、花瓣停落。
- **可进入建筑**：便利店、咖啡店、车站、奶奶家（4 处室内，带家具、灯光与真实交互：购物、售票、闸机、被炉、电视、床铺睡觉到次日早晨）。
- **小事件**：便利店晚开、列车延误、猫走失、花吹雪、废弃小屋的响动、傍晚庙会。
- **存档**：localStorage 保存天数/时间/位置/零钱/物品/信任/任务/关键世界状态，并每 90 秒自动保存。

## 技术要点

- 全部美术资源由代码生成：程序化 canvas 贴图（沥青、木纹、瓦、榻榻米、招牌、海报…）、`MeshToonMaterial` + 三段渐变 ramp 实现 cel-shading、自定义天穹 shader（日月星辰流云）。
- 无外部模型/音频：角色、建筑、列车均为参数化几何体搭建；音效全部由 WebAudio 合成（汽笛、道口警报、风、蝉鸣、鸟叫、门铃、脚步、雨声…）。
- 地形为解析高度场（盆地 + 丘陵 + 远山 + 河道下切 + 铁路走廊整平 + 神社小山），玩家/NPC/道具共用同一函数取样；碰撞为 AABB + 可踏上升面（站台、桥、石阶）。
- 室内通过“屋顶淡出”实现：进入建筑 footprint 时屋顶材质渐隐，出门渐显；门有独立碰撞体，关闭时阻挡玩家与相机。
- 性能：共享几何体缓存、实例化植被/货架/轨枕、小物件不投影、阴影相机跟随玩家。

```
src/data/                       NPC/任务/物品数据
src/ui/                         HUD、对话、任务日志、小地图、菜单
```

## 已知取舍

- 软件渲染（无 GPU）下帧率较低；真实 GPU 上流畅。
- NPC 寻路为“路线途经点 + 道口等待”，不做全局 A*；因此偶有贴墙行走，但不穿模。
- 天气只有晴天/雨天两种；季节固定为晚春樱花季。
