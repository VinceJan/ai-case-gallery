# 🏰 中世纪城堡与农田村庄 - 三渲二微缩三维场景 (Medieval Castle Diorama)

基于 **Three.js** 与现代前端技术构建的中世纪城堡、村庄与农田微缩景观模型，采用三渲二（Cel-shaded / Toon）艺术画风与 2.5D 像素小人交互。

---

## 🌟 核心特色与实现细节

### 1. 雕刻级微缩底座 (Diorama Plinth)
- **造型构图**：52×52 正方形底座，倒角平滑边缘，搭配石砌浮雕侧面与深色板岩基座压边。
- **阶梯地形**：
  - **后方高台**：崇山崖壁上的领地主堡与护城河。
  - **居中台地**：铺设鹅卵石道路的繁华村落与集市。
  - **前沿与两翼**：起伏的麦垄农田、水车磨坊、灌溉小溪与牲畜牧场。
  - **衔接结构**：石砌挡土墙、多级石阶、曲径小路与跨河拱桥，构成严整紧凑的“前低后高”微缩构图。

### 2. 三渲二质感与色彩美学 (Cel-shading Style)
- **色阶明暗**：运用 `MeshToonMaterial` 与离散阶梯明度贴图（Stepped Luminance Gradient Ramp），呈现纯净明确的阴影边缘。
- **材质细节**：程序化绘制的石砖灰浆、木筋房木框、茅草秸秆线条、陶瓦与板岩鳞片纹理。
- **色彩层次**：暖灰浅石、深色橡木、象牙白灰泥墙、金黄麦浪与碧绿草甸交相辉映。

### 3. 全防御态领地城堡 (Defensible Castle)
- **主堡 (Donjon Keep)**：多层石堡、角部石扶壁、木制防御外廊（Hoarding）、雉堞露台与高耸的主塔尖顶。
- **城墙雉堞与角楼**：四周封闭城墙带防御步道、箭窗（Embrasures）、四座锥形尖顶圆堡角楼。
- **城门与吊桥**：双塔瓮城门道、铁栅闸门（Portcullis）、悬吊铁链与横跨护城河的重型木板吊桥。
- **动态旗帜**：正弦波形几何体飘动动画，随风律动。

### 4. 生机勃勃的中世纪村落 (Medieval Village)
- **半木筋房 (Fachwerk)**：二层挑出悬臂（Jetty）、木制花槽与窗户。
- **繁华集市**：多顶彩色条纹遮阳棚货摊、蔬果货箱、酒桶与告示栏。
- **生活场景**：带辘轳与提桶的水井、装载粮食麻袋的大轮木马车。
- **铁匠铺**：红热发光的火炉（带动态跳动点光源）、铁砧、淬火水槽与工具架。
- **水风双磨坊**：右翼高丘上徐徐旋转的风车磨坊，沿水渠运转的木质水车磨坊。
- **谷仓与草垛**：宽敞谷仓与圆顶干草堆。
- **袅袅炊烟**：烟囱与锻炉上升的半透明微型烟团粒子。

### 5. 沃野田园与自然生态 (Farmland & Ecology)
- **麦垄与麦浪**：整齐翻耕的深色麦垄，密集实例麦穗，结合顶点着色器（Vertex Shader）驱动的风力起伏波纹。
- **农庄配件**：裂木围栏、破旧粗布衣稻草人、捆扎干草方块。
- **水系与桥梁**：自护城河跌水引出的灌溉水渠，配有石拱桥与木栈桥。
- **动物生态**：黑白斑点奶牛、棕色奶牛、绵羊带头部悠闲低头吃草动效。
- **环景树林**：周边点缀的卡通膨胀叶冠橡树与层叠松树，随风微晃，林间野花与蘑菇点缀。

### 6. 2.5D Q版像素小人 (Pixel Characters)
- **Q版小骑士**：盔缨、面罩、板甲、蓝色战袍、金纹章、小圆盾与红披风。
- **农田老农**：大草帽、背带裤、红格衬衫、手持草叉耕作。
- **动态特性**：
  - 4~5 FPS 复古定格帧步进动画（低帧率像素韵律）。
  - 地面接触投影：实时跟随的半透明柔和圆形阴影。
  - 行走巡逻：沿村落道路/田垄在多个路标点间漫步，停顿几轮后变换朝向，左右交替。
  - 脚步粒子：步履踏出时扬起秋叶与碎草尘土。
  - 极细微的呼吸与披风微动，色彩饱和度针对三渲二世界微调，融为一体。

### 7. 全景天气系统与沉浸交互 (Weather & UI)
- **5 款预设氛围**：
  1. ☀️ **晴朗白昼**：蔚蓝天穹、温和暖阳、低多边形浮云缓缓漂移。
  2. 🌅 **黄金落日**：夕阳红霞、拉长影子、村落暖黄窗灯与路灯亮起。
  3. 🌧️ **微雨朦胧**：青灰天幕、丝丝斜雨粒子、地面湿润微雾。
  4. 🌙 **静谧星夜**：幽蓝星空、闪烁繁星、草地村落萤火虫漂浮、火炉明亮。
  5. ❄️ **冬日初雪**：银白苍穹、轻柔摇曳飘落的雪花粒子。
- **原生 Web Audio 白噪音音效**：风声、鸟鸣、夜间虫鸣、雨滴声。
- **纯净观赏模式**：
  - 点击右上角「👁️」或按下键盘 `H` 键，可一键完全隐藏所有 UI，享受极致纯粹的 3D 微缩观赏！
  - 键盘 `1~5` 切换天气，`空格键` 启闭自动环绕旋转。
