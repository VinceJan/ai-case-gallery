# 樱花小镇 Sakura Town — 设计三件套

项目代号 `sakura_town`。目标：紧凑、闭环、会自行运转的日式乡镇生活模拟。
美术方向：当代日本地方小镇、轻怀旧动画背景式 cel/toon，晚春樱花期。

## 1. 设计简报（design-brief.md）

- **玩家承诺（一句话）**：在晚春的樱花小镇里过日子——按自己的节奏走动、打招呼、
  送礼、完成委托，看小镇随时光与天气自行运转，并在这里交到朋友。
- **目标感受**：温暖、轻怀旧、慢节奏但充实。没有失败画面；压力来自"时机"
  （商店关门前、雨天花不开、祭典只有一天）而非战斗。
- **主动词**：探索与交流（在小镇中走动，与 NPC 和物件交互）。
- **副动词**：送礼提升好感、购物/售卖经营金钱、接取并完成委托、按作息拜访。
- **每 5–30 秒重复**：走向一个 NPC/门/物件 → 按 E 交互 → 读一段对话或拿到
  一个物品/委托 → 从 HUD 看到状态变化。
- **每 1–5 分钟变化**：时钟推进（昼夜光照切换）、天气变化、NPC 沿路网移动换场、
  火车到站与道口栏杆、随机事件触发、商店每日补货。
- **如何失败**：不设 Game Over。错失时机（委托过期、祭典下雨顺延、关系冷却）
  即"软失败"，代价是奖励与剧情进度，玩家在次日/下次机会中恢复。
- **如何学习**：开场 NPC 主动搭话 teach 交互键；委托文本写明目标与地点；
  失败委托有明确反馈（"他今天不在店里"）。
- **奖励**：好感度（解锁深层对话、邀约、祭典同伴）、日元、物品、图鉴/关系面板。
- **风险**：时间持续流逝——想在一个游戏日内做很多事必须规划路线；
  下雨天户外 NPC 消失。
- **高手差异**：记住 NPC 作息与喜好，在正确时间出现在正确地点；
  倒卖商店低买高卖、把好感最高的 NPC 发展成委托来源。
- **非目标（本切片不做）：** 战斗、耕种系统、房屋装修、多人、乘车去邻镇、
  城市级规模。

## 2. 核心循环契约（core-loop.md）

> 玩家在镇中**走动并与 NPC/建筑交互**以提升好感、赚取日元、完成委托，
> 而**时间流动与天气**制造机会与限制；成功带来好感/金钱/物品并解锁新委托，
> 错失时机导致关系冷却与委托失败。

代码中的落点：

| 契约分句 | 实现 |
| --- | --- |
| 动词映射到真实输入 | WASD/方向键+触屏摇杆移动；E 交互；I/J/Esc 面板 |
| 目标在世界/HUD 可见 | 顶部时钟+天气、金钱、当前委托追踪、小地图标记 |
| 第一分钟内有压力 | 开场委托（帮面包店老板娘带话）限时 1 个游戏日 |
| 奖励改变状态而非仅视觉 | 好感度写入 TownState 并影响对话分支与事件资格 |
| 失败可教学 | 委托过期/目标不在均有明确提示文本 |
| 重启够快 | 标题界面一键继续/新开；睡眠推进到次日清晨 |

## 3. 关卡/空间规划（level-plan.md）

- **空间格式**：一张 160m×160m 的封闭小镇俯视平面，南低北高；相机第三人称跟随，
  边界以山、河、森林围合（"闭环曲面"）。
- **分区**（自北向南）：
  1. 铁路带（z≈-52）：东西向铁轨、车站（可进入候车室）、平交道口与栏杆。
  2. 商店街（z≈-16）：面包店、杂货店、咖啡馆、花店（全部可进入）+ 暖帘/看板/路灯。
  3. 中央广场（z≈4）：大樱花树、长椅、告示牌（任务板）、鸟居小径入口。
  4. 住宅区（四周）：4 栋可进入民宅（含玩家家，床=睡眠推进）+ 2 栋外观宅。
  5. 神社与后山（东侧 x≈46）：石阶、鸟居、本殿（可进入）、后方樱花林（赏樱名所）。
  6. 农田与河岸（南/东）：耕地、河流、木桥。
- **玩家起点**：自宅门前，面向中央广场；开场 NPC（邻居老师）走来 Teach 交互。
- **第一个决策**：接受/拒绝开场委托（拒绝则 10 分钟后再次提供，不惩罚）。
- **地标**：商店街暖帘、广场大樱树、神社鸟居——三个远可见锚点，小地图同步。
- **难度/ escalation**：委托奖励与解锁事件随好感与天数推进；第 3 天樱花祭
  （若下雨顺延）把全镇 NPC 汇聚神社，是第一个"高潮节拍"。
- **恢复节拍**：每夜睡眠回满状态并自动存档；雨天全镇节奏放慢、委托暂停刷新。
- **模块化**：建筑外观/内装由参数化工厂生成；NPC 作息=时间段×地点表；
  委托=模板×目标 NPC×物品；天气=状态机。新增内容不改核心系统。
