/**
 * Design brief / core loop / level plan — 樱花小镇
 */

# 设计摘要

## Player promise
在一座会自己运转的日式小镇里生活：观察、介入、留下痕迹，而不是被任务列表推着走。

## Target feeling
「这个地方不依赖我也存在；我愿意再多待一会儿。」

## Primary verb
**在场（Be there）** — 移动、观察、靠近。

## Secondary verbs
对话、购买、坐下、乘坐、帮助、发现。

## What the player repeats (5–30s)
走到有人的地方 → 看清他们在做什么 → 决定是否搭话/使用设施 → 得到世界反馈（对话、金钱、好感、氛围变化）。

## What changes (1–5 minutes)
时间推进 → 日程切换（上学/上班/回家）→ 天气与事件 → 交通节奏 → 灯光与街道气质。

## Core loop contract
玩家 **在小镇中停留并介入**（动词）以 **接近居民生活**（目标），同时 **时间与天气**（压力）不断改变可做之事；成功获得 **关系、金钱、故事与解锁**（奖励），失败只是 **错过这次窗口**（成本低，明天仍可再来）。

## Level / spatial plan
- 核心：车站广场 + 商店街
- 西：住宅区
- 东：学校 / 公园樱花
- 北：神社山丘
- 南：河川与仓库
- 环线铁路绕行全城，道路闭环
- 玩家出生在车站南侧，第一眼就能看到站牌、樱花与人

## Non-goals（本版不做）
- 写实 PBR / 大型开放世界
- 复杂战斗或经济模拟器
- 多人联机
- 外部 DCC 管线依赖

## Art direction
当代日本地方乡镇 · 晚春樱花 · 日式动画背景感 cel-shading · 温暖日照、略冷阴影 · 程序化招牌与材质。
