# 樱花小镇（Sakura Town）

一座会自己生活的 3D 日式小镇。电车准点经过，居民各有去处——你可以只是散步，也可以慢慢成为这里的一部分。

## 快速开始

```bash
cd sakura-town
npm install
npm run dev
```

浏览器打开 **http://127.0.0.1:5173**，点击「进入小镇」。

生产构建：

```bash
npm run build
npm run preview
```

## 这个小镇有什么

- **曲面小世界**：整座镇建在一颗小行星上，道路与铁路自然闭环，走远了地平线会弯。
- **车站与列车**：列车沿环线真实运行——进站、减速、开门、等候、离站；道口会在列车接近时关闭。
- **可进入的建筑**：车站、便利店、咖啡店、学校、神社、诊所、邮局、商店街、住宅，以及货架、柜台、桌椅等室内陈设。
- **居民生活**：8 位有名字的居民，上班族、学生、店员、老人、孩子、站员、医生——各有住处、班表、目的地与性格；雨天会打伞，会互相打招呼，也会去等车。
- **时间与天气**：昼夜光照、店内灯、路灯、营业时间、事件触发彼此关联；晴、多云、小雨、阵雨会改变出行与氛围。
- **交互密度**：门、自动售货机、赛钱箱、邮筒、长椅、商店购买、对话打听与示好。
- **任务从世界里长出来**：不是满屏感叹号，而是「早上去咖啡店」「黄昏去公园」「夜里便利店还亮着」这类事情。
- **随机事件**：列车晚点、突降阵雨、道路施工、小集市、短暂停电、小猫出没等，会传播到 NPC 对话与交通。
- **你的痕迹**：金钱、好感、帮助次数、任务进度会存档（浏览器 localStorage）。

## 玩法建议

1. 先在车站广场走一圈，熟悉小镇尺度。
2. 等一班列车进站，看道口如何工作。
3. 和居民聊天，听他们说起今天发生的事。
4. 帮人、购物、投赛钱，让「今日待办」自然完成。
5. 待到晚上——便利店和路灯会变成街道的光源。

## 技术

- Three.js + Vite，纯代码生成几何 / 程序化贴图 / 程序化音效，无外部模型与音频资源依赖。
- 圆柱/球面参数映射：逻辑在平面布局坐标中编写，再统一贴到球面。
- Cel-shading（MeshToonMaterial + 阶梯 gradient map）+ 柔和半球光，贴近日式动画背景。

## 项目结构

```
sakura-town/
  src/
    core/        游戏主循环、时间、天气、存档
    world/       行星曲面、道路、铁路、植被、世界状态
    buildings/   建筑工厂与室内
    entities/    玩家、NPC、列车
    systems/     交互、对话、任务、事件、音频
    ui/          HUD、对话框、地图、提示
    utils/       toon 材质与程序化贴图
```

## 说明

- 存档保存在浏览器 `localStorage`，键名 `sakura-town-save-v1`。
- 音频在首次点击「进入小镇」后解锁（浏览器自动播放策略）。
- 若画面偏暗/偏亮，可改 `src/core/Game.js` 中的 `toneMappingExposure`。
