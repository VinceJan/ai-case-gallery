# Willowmere · 微缩中世纪领地

Three.js 原创程序化微缩场景，无需模型或贴图素材。

## 运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`；预览：`npm run preview`。

## 操作

- 拖拽旋转，滚轮／双指缩放。
- 右上角切换晴、阴、雨、雪；滑杆调节一天的光照。
- 开关暂停环境与角色动画；底部按钮控制自动环绕、复位、全屏。

## 文件

- `src/world.js`：底座、分层地形、城堡、村落、农田、环境动画及静态几何合批。
- `src/actors.js`：原创像素骑士与农夫、低帧率动作、巡游、软影及脚步粒子池。
- `src/main.js`：渲染、观赏相机、天气与时间、交互。
- `src/style.css`：响应式展览式界面。

所有建筑、动物、植物与角色均程序生成。界面字体在线加载，离线时使用系统后备字体。需要支持 WebGL 的浏览器。
