# 🌸 樱花小镇 (Sakura Town)

> **日式乡镇生活模拟游戏 • 3D Anime Living Simulation**
> 基于 Three.js + TypeScript + Vite 构建的紧凑闭环曲面小镇

---

## 🌟 项目亮点与设计实现

本游戏严格按照项目要求，从零打造了一个**紧凑、高密度、具有闭环曲面与完整生命力**的日式小镇模拟世界：

1. **统一的日式动画背景美术 (Anime Cel/Toon Shading)**
   - 自定义 4 阶渐变阶梯的 Cel-shading / Toon 材质，带有冷色调柔和阴影与暖色阳光。
   - 动态曲面世界顶点形变（Curved World Horizon），小镇边缘呈现紧凑行星微曲面地平线。
   - 程序化手绘风河流着色器（Anime Water Shader），具备流动的焦散水纹、波光折射与岸边柔白泡沫。
   - 全程由代码与 HTML5 Canvas 生成高精度日式纹理（沥青路、斑马线、黄色点字导盲砖、瓦屋顶、榻榻米、障子纸门、さくらマート24H与木漏れ日招牌、自贩机饮料贴图、绘马祈愿牌等），**完全不依赖 Blender 等外部 DCC 工具与外部图片资产**。

2. **全建筑可进入与高精度室内陈设 (Fully Enterable Handcrafted Interiors)**
   - **さくら町駅 (Sakura Station)**：检票闸机（自动改札機・IC卡触碰板）、自动券卖机、候车木椅、带点字盲道的高架月台、悬挂式站名指示牌、遮雨棚。
   - **さくらマート 24H (Sakura Mart)**：感应式自动玻璃移门、收银台与 POS 机、加热炸鸡包子保温柜、两组零食饮料双面货架、冷光透明饮料冷藏展示柜、杂志架。
   - **珈琲 木漏れ日 (Cafe Komorebi)**：经典日式昭和/平成风吃茶店，包含吧台、虹吸壶、手冲咖啡架、高脚木凳、黑胶唱机与爵士唱片角、以及直面河岸落樱的户外遮阳伞木质露台。
   - **主角住宅 (Player House)**：两层日式和洋折衷民居，下沉式玄关（玄関・下駄箱・室内拖鞋）、六叠和室榻榻米（茶几、急须茶具、座蒲团、障子拉门）、二楼阁楼卧室（可交互睡眠跳过时间的被褥床铺、书桌笔记本电脑、眺望樱花树的阳台）。
   - **桜神社 (Sakura Shrine)**：西北山丘上的朱红大鸟居、参道石灯笼、手水舍（石水盘与竹柄杓）、拜殿与木条赛钱箱、可摇响祈福的金黄本坪铃与红白粗绳、悬挂全镇居民心愿的绘马架、三百年御神木（注连绳缠绕）、山顶眺望全镇的观景露台。
   - **南中学校 (Town School)**：校门钟楼、学生教室（黑板、讲台、粉笔擦、3x3 组学生课桌椅）、操场足球球门。

3. **运转不息的交通系统 (Living Transport & Vehicles)**
   - **闭环运行的两节编组日式电车 (2-Car EMU Commuter Train)**：沿环镇闭环轨道真实巡回、进站平滑减速靠泊、自动开启双侧滑动客门、报站发车铃声（车站专属音乐）、关门加速离站；玩家可随时**步入车厢落座，享受环镇全景车窗巡游**！
   - **经典日式铁道道口 (Railway Crossing - 踏切)**：当列车接近时，红黑相间横杆自动缓缓落下，双向交替红灯闪烁，响起清脆逼真的“当-当-当-当”警报音；列车驶过之后自动抬杆。
   - **可骑乘的日式市民自行车 (Mamachari Bicycle)**：带有前置钢丝车篮、可随行驶速度真实旋转的车轮辐条与曲柄；靠近按 `[F]` 骑乘，享受高速漫游与清脆的车铃声（`[Space]`）。

4. **有住所、作息、社交与反应的居民 (Living NPCs & Schedules)**
   - **ひな (Hina)**：便利店活力店员，早晨沿主街上班，白天在收银台，傍晚在河堤边散步。
   - **佐藤さん (Sato-san)**：神社老世話人，打扫落叶，守望御神木，关心走失的三花猫。
   - **葵 (Aoi)**：南中学美术生，教室上课，放学后坐在河畔樱花树下写生，暗恋莲。
   - **蓮 (Ren)**：活力足球少年，操场踢球，自贩机买汽水，到神社祈愿都大会优胜。
   - **高橋駅長 (Takahashi-san)**：戴制服大盖帽的老站长，全天值守月台，确保电车准点。
   - **健二 (Kenji)**：木漏れ日咖啡师店主，慢调手冲咖啡，聆听黑胶爵士乐。
   - **ミカン (Mikan)**：小镇吉祥物三花猫（三毛猫），戴着金黄小铃铛，在便利店前晒太阳、红桥上漫步、御神木下打盹；走近可抚摸并发出舒适的咕噜与喵叫！
   - **下雨天反应**：当下起春雨时，NPC 会自动撑起半透明的雨伞或进入咖啡厅避雨。

5. **24 小时昼夜、天气与环境音效 (Atmosphere & Web Audio Engine)**
   - 动态太阳月球轨迹（晨曦粉霞、正午碧空、傍晚暮色金辉、深夜星空月夜），街灯与室内橱窗在 18:30 黄昏准时自动点亮。
   - 5 种天气即时切换：🌸 樱吹雪（1200+ 片飘落翻滚的花瓣）、☀️ 晴朗、🌧️ 细雨（2200+ 滴雨线与湿润反射）、🌆 夕阳、🌙 星夜。
   - 基于 Web Audio API 的**纯程序化声音引擎**：脚步声、道口叮当声、电车轮轨敲击节奏声、发车站台八音盒旋律、手冲咖啡声、自行车双音车铃、神社本坪铃与投币撞击声、鸟鸣风声与潺潺流水。

6. **核心玩法与剧情任务 (Organic Gameplay & Quests)**
   - **任务 1：迷子的真鍮铃 (The Lost Bell of Mikan)**：在河畔桥边寻回三花猫丢失的金黄小铃铛，交还给神社佐藤老人，获得守护御守。
   - **任务 2：木漏れ日的出前 (Warm Brew Delivery)**：替咖啡店健二店主把刚萃取好的手冲热咖啡送往月台的高桥老站长手中，收获新鲜樱饼。
   - **任务 3：失落的画册 (The Lost Sketchbook)**：在樱花树下捡到葵的画册，发掘少年少女之间的小小心愿。
   - **任务 4：小镇摄影集 (Sakura Snapshot Record)**：使用手持 35mm 相机（`[C]` 开启取景框，带有三分构图辅助线与快门音），抓拍 4 处地标并永久收录入照片画册。
   - **睡眠与时间推进**：在民居榻榻米或二楼被褥中按下 `[E]` 即可休息并迎接清晨 6 点朝阳。
   - **本地自动存档 (LocalStorage)**：自动保留玩家位置、时间、天气、背包道具与任务状态。

## 🎮 操作指南 (Controls)

| 按键 / 操作 | 功能描述 |
| :--- | :--- |
| **W / A / S / D** (或方向键) | 玩家移动 / 控制自行车行进方向 |
| **Shift** | 疾跑加速 / 自行车高速冲刺 |
| **鼠标左键 / 右键拖拽** | 自由旋转镜头视野 (Orbit Camera) |
| **鼠标滚轮** | 镜头拉近 / 拉远缩放 (Zoom) |
| **V** | 切换 **第三人称 / 第一人称沉浸式视角** |
| **E** | **主要交互键**（与 NPC 对话、便利店买樱饼、喝咖啡、摇响神社铜铃祈福、在被褥睡眠跳过时间、登电车） |
| **F** | 骑上 / 离开市民自行车 (Mount/Dismount Mamachari) |
| **Space** | 骑车时鸣响清脆车铃 |
| **C** | 打开 / 关闭相机取景框拍照模式（点击快门抓拍照片） |
| **I** | 打开背包抽屉 (Inventory Drawer)，查看或食用已获得的樱饼与饮料 |
| **J** | 查看小镇任务日志 (Quest Chronicles) |
| **P** | 翻阅相机拍摄的照片画册 (Photo Album) |
| **T** | 快捷时间推进 (+2 小时) |

## 🚀 启动与构建 (Quick Start)

项目已配置完毕，无需任何外部下载即可本地启动与编译：

```bash
# 安装依赖 (如尚未安装)
npm install

# 启动本地开发热重载服务器 (端口 3000)
npm run dev

# 编译 TypeScript 与打包生产版本
npm run build

# 预览构建产物
npm run preview
```
