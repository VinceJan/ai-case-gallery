# 樱花小镇 · Sakura Town

当代日本地方乡镇背景的 3D 开放模拟小镇。Three.js + Vite，cel/toon 渲染，程序化几何与贴图，无外部素材依赖。

## 运行

```bash
cd sakura-town
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5188`。

生产构建：

```bash
npm run build
npm run preview
```

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 奔跑 |
| E | 交互（对话 / 购买 / 开门 / 坐下 / 祈祷） |
| 鼠标 | 视角跟随 |

触屏：左摇杆移动，右侧按钮奔跑。

## 世界

- **车站广场**（桜町駅）— 环状铁路闭合，列车进站、道口联动
- **商店街** — 面包店、书店、居酒屋、药房、五金、花店、洗衣店
- **便利店** — 24 小时，可购物
- **喫茶 さくら** — 咖啡店，有户外座位
- **住宅区** — 16 栋独立住宅 + 公寓，窗户夜间亮灯
- **桜町小学校** — 操场、钟楼
- **さくら神社** — 石阶、鸟居、眺望点
- **河渠与桥** — 西侧水路
- **公园长椅 / 自动售货机 / 邮筒 / 公告板 / 自行车**

## 系统

- **时间昼夜** — 影响光照、店铺营业、NPC 作息、夜间窗灯
- **天气** — 晴 / 阴 / 雨 / 雾；雨天 NPC 撑伞、老人留守
- **居民** — 12 位 NPC，有职业、住所、课表/班表、社会关系、对话
- **列车** — 环状线运行、进站停靠、道口关闭、可乘车
- **交互** — 购物、坐下、读公告、开灯、骑车、祈愿、丢垃圾
- **经济** — 金钱、背包、商店库存
- **委托与事件** — 从世界状态自然出现的小故事（落袋、雨天助人、夜灯、交友、环线）
- **秘密** — 特定地点/时段才触发的环境叙事
- **存档** — localStorage 自动保存金钱、物品、关系、flags

## 技术

- Three.js `MeshToonMaterial` + 梯度贴图 cel-shading
- 程序化 Canvas 贴图（招牌、橱窗、售货机、海报）
- 曲面世界：平坦游戏坐标 + 轻微球面下垂（`WORLD_RADIUS=420`），环状铁路闭环
- 测试钩子：`window.__THREE_GAME_TEST_HOOKS__`（seed / setState / setPausedForScreenshot）
