# Sakura Town — 游戏设计文档

## 玩家承诺
走进一座仍在自己运转的日本地方小镇：住民有家有班有关系，列车按时刻表进站，你的每一次购买、帮助和停留都会被记住。

## 目标感受
安静而有生命的日常感；探索时不断发现“这里原来还连着那里”；离开时想再回来看看今晚店里有没有开门。

## 主要动词
走 / 看 / 对话 / 交互 / 购买 / 乘坐 / 帮助 / 观察

## 次要动词
坐下 / 开关门灯 / 骑车 / 收集 / 完成委托 / 记住居民

## 5–30 秒循环
沿街步行 → 注意招牌/居民/声音 → 靠近交互（对话、购物、查看）→ 获得信息或物品 → 被下一个生活细节吸引

## 1–5 分钟循环
白天时段推进 → 通勤/放学/开店/关门改变小镇人流 → 火车到站带走和带来居民 → 天气或突发事件改变计划 → 玩家介入一段小故事

## 失败与重来
本作无硬性 Game Over。错过列车、店关门、居民不高兴都是可恢复的生活状态；时间继续流动，第二天会给出新的机会。

## 奖励与风险
- 奖励：金钱、好感、故事线索、隐藏空间、小镇因你而变的痕迹
- 风险：打扰居民降低好感、错过营业时间、雨天计划落空、把物品丢在奇怪的地方

## 高手做什么不同
记住居民作息和关系网；利用火车时刻；雨天观察谁没出门；发现后巷与夜间事件；用持久状态经营人情

## 核心循环契约
玩家在**紧凑的曲面小镇**中**探索与介入日常**，在**时间/天气/时刻表**的压力下做出小决定；成功获得**好感、金钱与世界痕迹**，失败只是**错过的时机**；重来即是新的一天。

## 非目标（本切片）
- 不追求写实 PBR / 大规模开放世界
- 不做战斗、不做复杂建造编辑器
- 不依赖外部付费素材服务
- 不做多人

## 世界结构
球面小世界（R≈95），车站广场为核，环状铁路闭合；商店街、住宅、学校、神社坡、河渠、公园沿道路自然生长。道路与铁路均能绕行回到出发点。

## 美术
日式动画背景 cel/toon：柔和分层色、暖阳冷影、克制轮廓、程序化招牌文字。

## 核心玩法来源
帮助居民的小委托从世界状态自然出现（店没开门、丢了东西、要赶车）；临时打工；购物与投喂；乘车巡游；收集与秘密观察。
