# 樱花小镇（Sakura Town）—— 简洁版提示词

> 项目代号：`sakura_town`

从零构建《樱花小镇》（Sakura Town）：一个紧凑、闭环曲面的日式乡镇生活模拟游戏。统一采用当代日本地方小镇、轻怀旧的动画背景式 cel/toon 美术，季节为晚春樱花期，低层住宅、铁路、商店街、神社等风貌协调一致。优先采用成熟轻量的浏览器 3D 路线，主要世界由代码生成，不依赖 Blender 等外部 DCC。建筑尽量可进入；NPC 有住所、关系、作息和有限决策；交通、商店、物品、昼夜天气、随机事件与玩家行为彼此影响并保留状态。规模以完成度为先：宁可更小、更密、更完整，不做城市级空壳；先做可玩的核心区域，再渐进扩展，最终交付一个会自行运转、真正有玩法和生命力的小世界。
