# 樱花小镇 Sakura Town 🌸

> 一个紧凑、闭环曲面的日式乡镇生活模拟游戏。晚春四月，樱花满开——
> 在这座会自行运转的小镇里，认识邻居、逛街购物、乘坐电车、参加夏日祭，
> 度过慢悠悠的日子。

**项目代号**：`sakura_town` ｜ **技术路线**：浏览器 3D（Three.js），主世界全部由代码程序化生成，
不依赖 Blender 等外部 DCC 工具。

---

## 快速开始

```bash
npm start          # 启动本地服务器（默认 8080 端口）
# 浏览器打开 http://localhost:8080
```

无需构建步骤——原生 ES Modules + importmap 直接加载 `vendor/three/`。
（也可以用任意静态服务器，如 `npx serve .`）

## 游戏内容

### 世界（约 260×280m 的闭环小镇）
- **樱花站**：站台、雨棚、会进站停靠的电车（可购票乘车去城市，2 小时后带回特产）
- **商店街**：带拱廊顶棚的商店街，6 家可进入店铺——海鸥便利店、小麦之路面包房、
  木漏日咖啡、纸间书店、千岁屋杂货铺、晚霞居酒屋
- **住宅区**：16 户住宅（含玩家住宅），全部可进入，内部按户型生成（榻榻米、矮桌、床、厨房…）
- **樱花神社**：小山上的神社，鸟居、石灯笼、绘马、注连绳，夏日祭的举办地
- **公园**：池塘、长椅、樱花树下花见胜地
- **水田与农场**：四块水田、谷仓、温室、稻草人
- **樱花桥与河流**：拱形木桥跨河，北岸樱林（世界由此闭环，边界有栅栏与封闭大门）
- **交通**：电车、2 辆环线汽车、1 辆会停站的巴士

### 居民（15 位 NPC）
每位 NPC 都有：**住所、工作场所、全天作息、性格、与玩家的好感度、与其他镇民的关系网**。
- 作息系统：按时刻表通勤、工作、吃饭、购物、散步、回家睡觉；雨天打伞急行、改变行程
- 有限决策：根据天气/时间/关系决定去哪；关系好的镇民相遇会停下聊天（关系增长）
- 对话系统：问候语随时间/天气/初次见面变化，闲聊会谈论工作、八卦其他镇民、樱花与祭典
- 社交玩法：**送礼**（投其所好效果更佳，高好感会回礼）、**邀请**（约会到指定地点见面）

### 经济与物品
- 6 家商店各有库存与零钱，价格随存货浮动，每日补货；可购买也可出售（按收购类别）
- 24 种物品：食物/饮品（恢复体力）、礼物（御守、花束、招财猫…）、工具（相机、伞、猫粮、车票）、
  材料与特产；初始 ¥2,500，可通过售卖特产、归还失物、神社御缘等方式增收

### 时间与天气
- 1 实际秒 = 2 游戏分钟（1x），可 2x/4x/暂停；睡觉可跳到次日早晨
- 完整昼夜循环：日出日落天空渐变、太阳/月亮/星星、黄昏暖光、夜晚路灯与窗户点亮
- 天气状态机：晴 / 多云 / 小雨 / 暴风雨（雷电）/ 樱花吹雪，平滑过渡并影响
  天空、雾、光照、粒子、音效与 NPC 行为（打伞、改道、避免外出）

### 随机事件（状态保留，写入存档）
1. **丢钱包**：某位镇民丢了钱包，在小镇某处闪亮——捡起并归还，获得谢礼与好感
2. **流浪猫**：神社附近出现饿猫，喂食（猫粮/食物）后它会跟着你，次日留下礼物
3. **夏日祭**（第 3 天公告，第 5 天傍晚）：摊位开张、镇民聚集神社、烟花大会、太鼓
4. **突发暴风雨** / **樱花吹雪**：天气骤变，镇民行为随之改变
5. **夜间集市**：商店街夜摊
6. **电车旅行**：乘车去城市，两小时后带回伴手礼

### 其他
- 小地图 + 大地图（镇民位置、关系着色、事件目标 ★）
- 12 个长期目标（认识镇民、成为好友、参加祭典、攒钱、拍照…）
- 事件记录册、自动存档（每日 + 手动 3 槽）、localStorage 持久化
- 程序化 WebAudio 音效：风、雨、鸟鸣、脚步、电车汽笛、雷声、祭典太鼓与烟花
- 拍照模式（P 键导出 PNG）
- 自适应画质：帧率过低时自动降低渲染负载

## 设计原则（对应需求）

- **完整度优先于规模**：小镇只有约 260m 见方，但每个区域都做实、可进入、有互动，
  不做城市级空壳
- **闭环世界**：河流、栅栏与封闭大门界定边界；所有系统（时间/天气/交通/商店/社交/事件）
  彼此影响并保留状态
- **代码生成**：建筑、地形、贴图（Canvas 程序化绘制，含日文招牌）、角色、动画全部代码生成
- **cel/toon 动画背景风**：`MeshToonMaterial` + 阶梯渐变、大色块樱花、硬边阴影、
  高饱和晚春配色；招牌文字用 Canvas 绘制日文/中文
- **渐进扩展**：布局数据（`layout.js`）与建筑/室内工厂完全参数化，
  新增一条道路、一栋房子、一位镇民只需加数据；寻路图自动重建

## 已知取舍

- 室内为独立场景（进入时切换），NPC 中只有当前建筑的负责人会出现在室内
- 阴影为单向光阴影贴图；低配设备自动降画质
- 音效为程序化合成（无外部音频资源）
